- Two pointers, Sliding window, KMP (advanced)

- Count, Complement lookup, Group by key

- Opposite ends, Same direction (fast/slow)

- Fixed size, Variable size, Hash for validity

## Stack
- Monotonic stack, Valid parentheses, Next greater

- Sort + pick, Intervals, Exchange argument
