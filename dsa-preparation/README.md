## Per-Topic Layout

Each topic folder contains:

| File/Folder | Purpose |
|-------------|---------|
| `problems.md` | Curated problems with links, difficulty, pattern, edge cases |
| `notes.md` | Intuition, patterns, mistakes, company expectations |
| `solutions/` | C# solution files (one per problem) |

## How to Use

1. **Follow the order** — Topics are sequenced from beginner to advanced.
2. **Read notes first** — Understand patterns before coding.
3. **Solve problems** — Try yourself, then compare with solutions.
4. **Revision folder** — Use before interviews: pattern recap, must-do list, mistakes checklist.
