# Design Problems — Notes

## LLD Best Practices

1. **Clarify requirements** — Ask about scale, constraints, use cases
2. **Identify entities** — Classes, their responsibilities
3. **Define interfaces** — Public API first
4. **Handle concurrency** — Locks, thread-safety if applicable
5. **Edge cases** — Null, empty, limits

## Common Patterns

- **HashMap + DLL** — LRU, LFU
- **Two Stacks** — Min stack, Queue from stacks
- **State Machine** — Elevator, Vending machine
- **Token Bucket / Sliding Window** — Rate limiter
